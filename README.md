# Portal Web de Automóviles — Catálogo y Registro de Usuarios

Aplicación web dedicada al sector automotriz que combina una presentación visual atractiva de vehículos con un sistema de registro de usuarios. Diseñada con una estructura clara, navegación fluida y formularios interactivos para mejorar la experiencia del visitante.

## Características principales
* **Sistema de registro de usuarios:** Formulario interactivo con campos estructurados y validación de datos para el registro de nuevos visitantes o clientes.
* **Catálogo y exhibición automotriz:** Sección visual organizada para presentar modelos, características y detalles destacados de los vehículos.
* **Diseño moderno y responsivo:** Interfaz adaptable a distintos tamaños de pantalla (computadores, tabletas y teléfonos móviles).

## Lenguajes y herramientas utilizadas
* **Desarrollo Web:** HTML5, CSS3, JavaScript
* **Control de versiones:** Git y GitHub Desktop
